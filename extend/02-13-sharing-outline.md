# OpenCode & 上下文工程 分享大纲

> 2025-02-13 分享会

## 一、OpenCode 是什么？（3分钟）

- 区别于普通 AI 助手：**有文件系统权限、能在终端操作**
- 核心价值：AI 真正能"动手"改你的代码
- 本质：**上下文工程** 决定它有多聪明

---

## 二、快速上手注意点（5分钟）

| 事项 | 说明 |
|------|------|
| Windows 用户 | 务必用 WSL，避开兼容性坑 |
| 安装方式 | 推荐 `bun install -g opencode-ai` |
| 首次启动 | 有免费模型可用，先体验再配置付费 |
| 配置 API | 用 `/connect` 或 `opencode auth login` |
| 白屏问题 | `export OPENCODE_DISABLE_DEFAULT_PLUGINS=true` |

## 三、上下文工程核心（10分钟）

### 1. AGENTS.md — 项目说明书

- **作用**：告诉 AI 项目结构、代码风格、禁忌
- **生成**：`/init`（小项目）或 `/init-deep`（大项目）
- **要点**：生成后根据需要微调，不是一劳永逸

### 2. Compact 机制 — 对话压缩

- **自动触发**：上下文占用到 80% 左右
- **手动触发**：`/compact`
- **学会看**：标题下方的 token 数和百分比
- **关键**：任务过长时主动压缩，避免丢失上下文

### 3. 持久化记忆（.agent_workspace）

| 目录 | 用途 |
|------|------|
| log/ | 做了什么（便于断点恢复） |
| plan/ | 要做什么 |
| experience/ | 踩过的坑（主观经验） |
| knowledge/ | 技术知识（客观事实） |
| archive/ | 过期内容归档 |

## 四、进阶使用（5分钟）

### oh-my-opencode 插件

- 解锁多智能体协作能力
- 安装后让 AI 自己装：给它 GitHub 链接即可

### 多智能体触发

| 语法 | 用途 |
|------|------|
| `@oracle` | 架构决策、深度调试 |
| `@explore` | 搜索当前代码库 |
| `@librarian` | 搜索外部文档、开源示例 |

### 配置切换（omo-switch）

- 不同场景用不同配置（写论文 / 日常开发 / 研究任务）
- `omo-switch apply <配置名>`

---

## 五、安全与效率提醒（5分钟）

### 安全

- 敏感代码**不要**用可能用于训练的免费额度（如 gemini-cli）
- API 中转站有便利但需自行评估风险

### 效率技巧

- **语音输入**：豆包 App，设快捷键，适合描述复杂需求
- **多会话**：`Ctrl+X L`，同时跑多个独立任务
- **外部编辑器**：`export EDITOR=vim`，长 prompt 更方便

---

## 六、总结

1. **上下文工程 > 模型能力**：好的 AGENTS.md 比换模型更有效
2. **学会管理上下文**：看 token 占用、主动 compact、用记忆结构
3. **从简单开始**：先用免费模型跑通流程，再考虑付费配置
